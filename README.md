## Deskripsi Proyek
Proyek akhir ini bertujuan untuk menganalisis sentimen ulasan pelanggan e-commerce guna mengklasifikasikan sentimen positif dan negatif menggunakan algoritma Machine Learning.

## Sumber Dataset
- Dataset: PRDECT-ID Dataset (Ksternal/Kaggle yang kredibel)
- Kolom Utama: Kategori, Nama Produk, Harga, Rating, Ulasan, dan Sentimen.

## Cara Menjalankan Program
1. Pastikan library Python (pandas, scikit-learn, matplotlib, seaborn) sudah terinstal.
2. Buka file `final_project.ipynb` di Jupyter Notebook atau Google Colab.
3. Jalankan sel secara berurutan dari atas ke bawah.
